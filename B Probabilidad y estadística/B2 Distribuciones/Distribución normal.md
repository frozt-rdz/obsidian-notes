La distribución normal es probablemente la distribución más importante de toda la estadística.

Tiene esta forma de campana:

```
                    *
                 *     *
               *         *
             *             *
           *                 *
        ***                   ***
------|------|------|------|------|------
     μ-2σ    μ-σ     μ     μ+σ   μ+2σ
```

Se caracteriza principalmente por dos parámetros:

### Media μ

Indica el centro de la distribución.

Por ejemplo:

```
Media = 70 kg
```

significa que el centro de los datos está alrededor de 70 kg.

### Desviación estándar σ

Indica qué tan dispersos están los datos.

Una desviación pequeña:

```
       ****
     ********
   ************
------70-------
```

significa que los datos están muy concentrados.

Una desviación grande:

```
          ***
        *******
      ***********
    ***************
------70------------
```

significa que hay mayor dispersión.

# Un ejemplo sencillo

Supongamos que las calificaciones de un examen siguen aproximadamente una distribución normal:

μ=70\mu = 70 σ=10\sigma = 10

Entonces:

```
Media = 70
Desviación estándar = 10
```

Una calificación de 70 está exactamente en el centro.

Una de 80 está una desviación estándar por encima.

Una de 60 está una desviación estándar por debajo.

```
50       60       70       80       90
|--------|--------|--------|--------|
 -2σ      -1σ       μ       +1σ      +2σ
```
