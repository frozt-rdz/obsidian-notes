Esta regla es muy útil para recordar rápidamente cómo se distribuyen los datos de una normal.

Para una distribución normal:

### Dentro de ±1 desviación estándar

Aproximadamente:

$$68\%$$

de los datos.

### Dentro de ±2 desviaciones

Aproximadamente:

$$95\%$$

### Dentro de ±3 desviaciones

Aproximadamente:

$$99.7\%$$

Visualmente:

```
                 99.7%
        <------------------------>

             95%
        <--------------->

            68%
         <-------->

     -3σ   -2σ   -1σ   μ   +1σ   +2σ   +3σ
```

---

## Ejemplo

Supongamos:

$$\mu=100$$
$$\sigma=15$$

Entonces:

### ±1σ

$$100-15=85 $$
$$100+15=115$$

Aproximadamente el 68% de los datos está entre:

$$85 \leq X \leq 115$$

### ±2σ

$$70 \leq X \leq 130$$

aproximadamente 95%.

### ±3σ

$$55 \leq X \leq 145$$

aproximadamente 99.7%.

# ¿Qué pasa con los valores extremos?

Aquí empieza a aparecer una idea fundamental para las pruebas estadísticas.

Si observamos:

$$Z=0$$

el dato es completamente normal respecto a la media.

Si:

$$Z=1$$

sigue siendo bastante común.

Si:

$$Z=2$$

ya es relativamente raro.

Si:

$$Z=3$$

es bastante raro.
