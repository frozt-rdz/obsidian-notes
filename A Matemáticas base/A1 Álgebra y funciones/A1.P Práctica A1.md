## Mini-proyecto en Python

Reconstruye las pendientes y compara su mediana con la pendiente entre extremos. Si cambias fechas, conserva sus diferencias reales.

```python
import numpy as np
t = np.arange(10, dtype=float)
y = np.array([0., 1., 1., 2., 4., 3., 5., 5., 6., 8.])  # Simulados, mm
i, j = np.triu_indices(len(t), k=1)
pendientes = (y[j]-y[i])/(t[j]-t[i])
print(f"número de pendientes = {len(pendientes)}")
print(f"mediana = {np.median(pendientes):.6f} mm/año")
print(f"mediana por década = {10*np.median(pendientes):.6f} mm/década")
print(f"pendiente entre extremos = {(y[-1]-y[0])/(t[-1]-t[0]):.6f} mm/año")
print(f"empates = {np.sum(y[j] == y[i])}; S = {int(np.sign(y[j]-y[i]).sum())}")
assert len(pendientes) == 45
```

Salida esperada:

```text
número de pendientes = 45
mediana = 0.800000 mm/año
mediana por década = 8.000000 mm/década
pendiente entre extremos = 0.888889 mm/año
empates = 2; S = 41
```

Entrega una frase con periodo, tasa y procedencia simulada. Hay diez observaciones anuales y nueve años transcurridos.
