## Mini-proyecto en Python

Simula el nivel curvo y comprueba que integrar su tasa devuelve el cambio. Los trapecios son exactos para esta tasa lineal.

```python
import numpy as np
from scipy.integrate import trapezoid
t = np.arange(5, dtype=float)
h = 10+3*t+0.2*t**2  # Nivel simulado, mm
v = 3+0.4*t
cambio = trapezoid(v, x=t)
gradiente = np.gradient(h, t, edge_order=2)
print(f"cambio por integral = {cambio:.1f} mm")
print(f"cambio directo = {h[-1]-h[0]:.1f} mm")
print("tasas numéricas =", np.round(gradiente, 6).tolist())
print("coinciden con tasa exacta =", np.allclose(gradiente, v))
assert np.isclose(cambio, h[-1]-h[0])
```

Salida esperada:

```text
cambio por integral = 15.2 mm
cambio directo = 15.2 mm
tasas numéricas = [3.0, 3.4, 3.8, 4.2, 4.6]
coinciden con tasa exacta = True
```
