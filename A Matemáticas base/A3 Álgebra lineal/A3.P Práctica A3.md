> Colinealidad. Tres datos tienen tiempo 2 y respuesta 5. ¿Son únicos los coeficientes?

## Mini-proyecto en Python

Ajusta dos celdas simuladas con fechas comunes. Conserva la correspondencia entre columnas y ubicaciones.

```python
import numpy as np
t = np.arange(5, dtype=float)
ruido = np.array([-0.8, 0.6, 1., -0.6, -0.2])
Y = np.column_stack([2.8+0.6*t+ruido, 5-0.2*t])  # Simulados, mm
X = np.column_stack([np.ones_like(t), t])
beta, _, rango, _ = np.linalg.lstsq(X, Y, rcond=None)
E = Y-X@beta
print("interceptos =", np.round(beta[0], 6).tolist())
print("pendientes mm/década =", np.round(10*beta[1], 6).tolist())
print("SSE por celda =", np.round(np.sum(E**2, axis=0), 6).tolist())
print(f"rango = {rango}; ortogonalidad = {np.allclose(X.T@E, 0, atol=1e-12)}")
assert rango == 2
```

Salida esperada:

```text
interceptos = [2.8, 5.0]
pendientes mm/década = [6.0, -2.0]
SSE por celda = [2.4, 0.0]
rango = 2; ortogonalidad = True
```

La segunda celda está exactamente sobre su recta por construcción. Esto no prueba ausencia de incertidumbre en un sensor real.
